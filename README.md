# Task Manager App

A minimal Angular application scaffolded manually for the `TaskManagerApp` workspace.
Instructions to run TaskManagerApplication:
Environment.ts have application setting: language, offlinemode ,serverUrl
Application will run by default offline mode set true, and Hebrew culture.
Once TaskManager server , Restart TaskManagerApplication set environment.ts with serverUrl and offlinemode set to false.

## Setup

```bash
npm install
npm start
```

## Available scripts

- `npm start` - runs the app in development mode
- `npm run build` - builds the app for production
- `npm test` - runs unit tests
